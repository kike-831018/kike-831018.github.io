# Portafolio personal — Kike

Portafolio web personal desarrollado con HTML, CSS y JavaScript, preparado para publicarse en GitHub Pages.

## Proyectos

- **TourInvest:** plataforma de inversión turística en Colombia.
- **Outfit:** asistente personal de imagen.
- **Triqui:** juego de estrategia desarrollado en Flutter.
- **Mis apps:** aplicación para consultar las aplicaciones instaladas en el dispositivo.

## Tecnologías

- HTML5
- CSS3
- JavaScript
- Flutter y Dart
- Git y GitHub
